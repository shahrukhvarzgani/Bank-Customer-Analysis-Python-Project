# Bank Marketing Campaign Analysis

## Overview

This project analyzes a bank marketing dataset sourced from Kaggle to predict whether a customer will subscribe to a Certificate of Deposit (CD) product. The goal is to identify key customer segments most likely to respond positively to marketing campaigns, enabling more targeted and efficient outreach strategies.

## Project Workflow

* **Feature Engineering** — Transformed and encoded categorical variables, created new features from existing customer demographic and behavioral data
* **Exploratory Data Analysis** — Visualized customer distributions, subscription rates, and feature correlations to uncover patterns in the data
* **Model Training \& Evaluation** — Built and compared Logistic Regression and Random Forest classification models to predict CD subscription likelihood
* **Hyperparameter Tuning** — Optimized model parameters to improve predictive performance

## Technologies Used

* Python
* Pandas, NumPy
* Scikit-learn
* Matplotlib, Seaborn

## Dataset

Bank marketing dataset sourced from Kaggle containing customer demographic, financial, and campaign interaction features.
